# Stimmprofile

Hier liegen die Stimmprofile der Personen, für die geschrieben wird - eine Datei pro Person
oder Kunde, z.B. `andy.md`, `kunde-mueller-gmbh.md`.

Vorlage und Analyseverfahren: `../references/stimmprofil.md`

Der Ordner ist beim ersten Einsatz leer. Profile entstehen, sobald echte Textproben
vorliegen: analysieren, Profil vorschlagen, hier ablegen.
