# Deutsche KI-Marker

Vollständige Musterliste für deutsche Texte. Reihenfolge nach Auffälligkeit: Was oben steht,
verrät einen Text am schnellsten.

## 1. Einstiegsfloskeln

Der häufigste einzelne Verräter. Streiche den ersten Satz und prüfe, ob etwas fehlt. Meist
nicht.

**Streichen:** In der heutigen schnelllebigen Welt / In der heutigen digitalen Welt / Im
digitalen Zeitalter / In einer Zeit, in der ... / In einer Welt, in der ... / Immer mehr
Menschen fragen sich ... / Stellen Sie sich vor: ... / Tauchen wir ein / Lassen Sie uns
eintauchen in die Welt von ... / Eines vorweg: / Kaum ein Thema wird derzeit so intensiv
diskutiert wie ...

**Vorher:**
> In der heutigen schnelllebigen Geschäftswelt, in der Effizienz immer wichtiger wird,
> spielt die Automatisierung von Prozessen eine zentrale Rolle.

**Nachher:**
> Wer Prozesse automatisiert, spart Zeit. Die Frage ist nur, welche.

Ersetze den Einstieg durch das, was der Text tatsächlich sagen will. Ein guter erster Satz
enthält eine Information, eine Behauptung oder eine Szene - keine Weltlage.

## 2. Abschlussfloskeln

Zweithäufigster Verräter. KI beendet jeden Abschnitt mit einer Zusammenfassung.

**Streichen:** Zusammenfassend lässt sich sagen / Abschließend lässt sich festhalten /
Insgesamt lässt sich sagen / Im Großen und Ganzen / Letztendlich kommt es darauf an /
Fazit: ... (wenn nur wiederholt wird) / Denken Sie daran: Jeder kleine Schritt zählt /
Die Zukunft bleibt spannend / Es bleibt abzuwarten, wohin die Reise geht / Eines ist
sicher: ...

**Regel:** Wenn der Schlussabsatz nur wiederholt, was oben stand, ersatzlos streichen. Ein
Text darf mit dem letzten Argument enden. Falls ein Schluss nötig ist, dann mit etwas Neuem:
einer Konsequenz, einer offenen Frage, einer konkreten Handlung.

**Vorher:**
> Zusammenfassend lässt sich sagen, dass eine durchdachte Content-Strategie entscheidend
> für den langfristigen Erfolg ist. Die Zukunft bleibt spannend.

**Nachher:**
> (streichen)

## 3. Die Wortliste

Diese Wörter sind nach 2023 explosionsartig häufiger geworden. Einzeln unauffällig, in
Kombination ein sicheres Erkennungszeichen. Faustregel: Höchstens eines dieser Wörter pro
Absatz, und nur wenn es wirklich das treffende ist.

**Adjektive:** transformativ, nahtlos, tiefgreifend, ganzheitlich, skalierbar, wegweisend,
bahnbrechend, visionär, disruptiv, revolutionär, beispiellos, entscheidend, essenziell,
elementar, proaktiv, innovativ, zukunftssicher, reibungslos, mühelos, datengetrieben,
dynamisch, intuitiv, robust, maßgeschneidert, vielfältig, vielschichtig, vielseitig,
umfassend, akribisch, einzigartig, immersiv, hochmodern, vorausschauend, prädiktiv,
renommiert, atemberaubend, beeindruckend, wertvoll, effektiv, effizient (als Selbstlob),
maßgeblich, unerlässlich, sorgfältig kuratiert, sauber, präzise

**Substantive:** Lösung (als Selbstbezeichnung: "unsere ganzheitliche Lösung"), Plattform
(dito), Mehrwert, Synergie, Paradigma, Landschaft (übertragen: "Medienlandschaft",
"Bildungslandschaft"), Ökosystem (übertragen), Schlüsselrolle, Grundpfeiler, Meilenstein,
Spielveränderer, Gamechanger, Zusammenspiel, Herzstück, Fundament (übertragen), Reise
(übertragen: "Ihre Reise zu ..."), Werkzeugkasten, Leitfaden, Deep Dive

**Verben:** verdeutlichen, unterstreichen, hervorheben, beleuchten, erschließen, entfesseln,
befähigen, ermöglichen, optimieren, aufwerten, neu definieren, revolutionieren, demokratisieren,
fördern, übertreffen, beschleunigen, eintauchen, meistern, navigieren (übertragen), gestalten
(ohne Objekt), prägen

**Ersatzregel:** Kein Synonym suchen, sondern konkretisieren oder streichen. "Eine
maßgeschneiderte Lösung" → "eine Lösung, die auf Eure Warenwirtschaft aufsetzt". Wenn nichts
Konkretes bekannt ist: weglassen.

## 4. Funktionsverbgefüge und Nominalstil

Deutschspezifisch und sehr verräterisch. KI ersetzt einfache Verben durch
Substantiv-plus-Hilfsverb-Konstruktionen.

| Statt | Besser |
|---|---|
| eine Rolle spielen | wichtig sein / zählen / (streichen) |
| zur Anwendung kommen/bringen | anwenden / benutzen |
| Berücksichtigung finden | berücksichtigen |
| in Betracht ziehen | überlegen / prüfen |
| eine Entscheidung treffen | entscheiden |
| Unterstützung bieten | helfen / unterstützen |
| zum Einsatz kommen | eingesetzt werden / benutzt werden |
| die Durchführung von X | X durchführen |
| die Optimierung der Prozesse | Prozesse verbessern |
| im Rahmen von | bei / in |
| unter Berücksichtigung von | wenn man X beachtet |
| in Anbetracht dessen, dass | weil |
| es gilt zu beachten | (streichen) |
| Verwendung finden | benutzt werden |
| eine Verbesserung erfahren | besser werden |

**Vorher:**
> Die Implementierung einer strukturierten Vorgehensweise kann zur Optimierung der
> internen Abläufe beitragen und findet in vielen Unternehmen Anwendung.

**Nachher:**
> Wer strukturiert vorgeht, arbeitet schneller. Viele Firmen machen das längst so.

## 5. Bedeutungsaufblähung

Sätze, die nur behaupten, dass etwas bedeutsam ist oder zu einem größeren Trend gehört.

**Signalwörter:** spielt eine zentrale/entscheidende/wichtige Rolle, ist ein Beleg für, zeugt
von, markiert einen Wendepunkt, steht sinnbildlich für, ist Ausdruck eines größeren Trends,
gewinnt zunehmend an Bedeutung, ist wichtiger denn je, rückt immer stärker in den Fokus,
ist aus dem Alltag nicht mehr wegzudenken, unterstreicht die Bedeutung von, bildet die
Grundlage für

**Reichweiten-Verstärker:** für die gesamte Branche / branchenweit / für den gesamten
Mittelstand / weit über X hinaus. Hängt an einer Einzelaussage und behauptet Tragweite, die
niemand geprüft hat. Streichen.

**Zeit-Antithesen:** wer frühzeitig investiert, profitiert langfristig / kurzfristiger
Aufwand, nachhaltiger Nutzen / was heute gilt, ist morgen Standard / die Weichen für morgen
stellen. Immer inhaltsleer, immer streichen.

**Leerformeln:** die Anforderungen von heute / die Herausforderungen von morgen / auf die
Bedürfnisse zugeschnitten / in einem zunehmend komplexen Umfeld.

**Vorher:**
> Die Gründung des Vereins im Jahr 1998 markierte einen Wendepunkt für das kulturelle Leben
> der Stadt und unterstreicht die wachsende Bedeutung bürgerschaftlichen Engagements.

**Nachher:**
> Der Verein wurde 1998 gegründet und organisiert seitdem das Stadtfest.

## 6. Negativ-Positiv-Muster

Extrem häufig, besonders in Social-Media-Texten. Alle Varianten gehören zur selben Familie.

**Muster:** Es geht nicht um X, sondern um Y. / Nicht X. Sondern Y. / Vergiss X. Y ist es. /
Weniger X, mehr Y. / X ist tot, Y ist die Zukunft. / Das ist kein X, das ist ein Y. /
Nicht nur ..., sondern auch ... / Es ist nicht bloß ..., es ist ...

**Vorher:**
> Es geht nicht um mehr Reichweite. Es geht um echte Verbindung. Nicht Follower. Fans.

**Nachher:**
> Reichweite bringt wenig, wenn niemand antwortet. Interessanter ist, wer zurückschreibt.

Ausnahme: Eine einzelne bewusste Antithese in einem langen Text ist normale Rhetorik. Zwei
im selben Absatz sind ein Marker.

## 7. Dreierregel und Symmetrie

KI gruppiert alles in Dreiergruppen: drei Adjektive, drei Beispiele, drei Unterpunkte, drei
Absätze pro Abschnitt.

**Vorher:**
> Unsere Software ist schnell, sicher und skalierbar. Sie hilft Teams, Prozesse zu
> strukturieren, Zeit zu sparen und Fehler zu vermeiden.

**Nachher:**
> Die Software ist schnell und läuft auch bei 200 gleichzeitigen Nutzern stabil. Teams
> nutzen sie vor allem, um Übergaben zu dokumentieren.

**Prüfung:** Zähle die Aufzählungen im Text. Wenn mehr als die Hälfte drei Glieder hat,
kürze einige auf zwei oder erweitere auf vier. Ungerade Struktur wirkt menschlich.

Ebenso auflösen: gleich lange Bulletpoints, gleich lange Absätze, jeder Abschnitt mit
gleichem Aufbau (Behauptung - Begründung - Beispiel).

## 8. Übergangswort-Inflation

KI beginnt fast jeden Absatz mit einem Konnektor.

**Verdächtig:** Darüber hinaus, Zudem, Außerdem, Überdies, Ferner, Des Weiteren, Nicht zuletzt,
Vor diesem Hintergrund, Dabei gilt, Gleichwohl, Dennoch, Letztendlich, Somit, Folglich,
Bei all dem

**Regel:** Höchstens jeder dritte Absatz darf mit einem Konnektor beginnen. Deutsche Prosa
verbindet Absätze über den Inhalt, nicht über Signalwörter. Streiche den Konnektor und prüfe,
ob der Übergang trotzdem trägt. Meist ja.

## 9. Hedging im Konjunktiv

Absicherung statt Aussage.

**Muster:** könnte potenziell / kann unter Umständen dazu beitragen / dürfte in vielen Fällen /
es lässt sich argumentieren, dass / möglicherweise ein gewisser Einfluss / kann helfen, X zu
verbessern / sollte idealerweise

**Vorher:**
> Eine klare Struktur könnte potenziell dazu beitragen, die Lesbarkeit möglicherweise zu
> verbessern.

**Nachher:**
> Eine klare Struktur macht den Text lesbarer.

Nur dann hedgen, wenn die Unsicherheit echt und relevant ist. Dann aber benennen, warum:
"Ob das langfristig hält, weiß niemand - dafür gibt es die Software erst seit zwei Jahren."

## 10. Vage Autoritäten

**Muster:** Experten sind sich einig / Studien zeigen / Untersuchungen belegen / Fachleute
empfehlen / Branchenbeobachter gehen davon aus / Viele Unternehmen setzen bereits auf /
Es hat sich gezeigt, dass

**Regel:** Entweder konkret belegen (wer, wann, wo) oder als eigene Einschätzung
kennzeichnen ("Aus meiner Erfahrung ..."). Keine erfundenen Studien, keine erfundenen
Zahlen. Wenn kein Beleg vorliegt, Aussage abschwächen oder streichen und dem User sagen,
dass hier eine Quelle fehlt.

## 11. Doppelpunkt-Dramatik und Ein-Wort-Sätze

Aus dem LinkedIn-Copywriting übernommen und von KI massiv überstrapaziert.

**Muster:** Das Ergebnis: mehr Umsatz. / Die Wahrheit: niemand liest das. / Der Grund? Ganz
einfach. / Und plötzlich: Stille. / Punkt. / Wirklich. / Und das ändert alles.

**Vorher:**
> Der Effekt: mehr Anfragen. Deutlich mehr. Und das verändert alles.

**Nachher:**
> Danach kamen etwa doppelt so viele Anfragen wie vorher.

Eine solche Konstruktion pro Text ist Stilmittel. Drei sind Slop.

## 12. Rhetorische Fragen

Besonders als Absatzeinstieg oder Überschrift.

**Muster:** Doch was bedeutet das konkret? / Warum ist das so wichtig? / Wie gelingt das in
der Praxis? / Klingt kompliziert? Ist es nicht. / Was heißt das für Sie?

**Sonderfall Schlussfrage:** Sind Sie bereit? / Bist Du bereit? / Wie handhabt Ihr das? /
Was hält Dich noch davon ab? Das ist der häufigste deutsche Post-Abschluss überhaupt.
Streichen oder durch eine Aufforderung ersetzen, auf die es eine echte, konkrete Antwort
gibt ("Schreib mir, wie ihr heute Aufträge erfasst").

**Regel:** Höchstens eine rhetorische Frage pro Text, und nur, wenn die Antwort danach
wirklich überrascht. Sonst in eine Aussage umwandeln.

## 13. Coaching-Ton und Leseransprache

**Muster:** Sie fragen sich jetzt vielleicht ... / Kommt Ihnen das bekannt vor? / Sie sind
damit nicht allein. / Der erste Schritt ist getan. / Jetzt sind Sie dran! / Legen wir los! /
Viel Erfolg dabei!

Streichen, außer der Zielkanal verlangt es ausdrücklich (z.B. ein Newsletter mit
Call-to-Action). Dann höchstens einmal, am Ende.

## 14. Werbesprache

**Signalwörter:** eingebettet in, im Herzen von, malerisch, atemberaubend, ein Muss für jeden,
verwöhnt die Sinne, bietet ein unvergessliches Erlebnis, überzeugt durch, punktet mit,
besticht durch, verbindet X mit Y auf einzigartige Weise, mit Liebe zum Detail, seit jeher,
traditionsreich, das gewisse Etwas

**Vorher:**
> Eingebettet in die malerische Hügellandschaft des Sauerlands besticht das Hotel durch
> seine einzigartige Verbindung von Tradition und Moderne.

**Nachher:**
> Das Hotel liegt am Ortsrand von Winterberg. Der Altbau stammt von 1912, der Anbau mit den
> Tagungsräumen von 2019.

## 15. Synonymkarussell

KI wechselt zwanghaft die Bezeichnung für dieselbe Sache: "das Unternehmen" → "die Firma" →
"der Betrieb" → "das Traditionshaus" → "der Marktführer".

**Regel:** Beim gleichen Wort bleiben. Wiederholung ist im Deutschen erlaubt und wirkt
natürlicher als Variation um jeden Preis. Alternativ: Pronomen oder den Satz umbauen.

## 16. Typografie und Formatierung

- **Gedankenstriche:** KI setzt Halbgeviertstriche (–) und Geviertstriche (—) inflationär.
  Die meisten lassen sich durch Komma, Punkt oder Klammer ersetzen. Höchstens einer pro
  Absatz, und nur als echter Einschub.
- **Fettung:** Keine mechanisch gefetteten Schlüsselbegriffe mitten im Fließtext. Fettung
  nur für echte Zwischenüberschriften.
- **Listen mit fetten Stichwörtern und Doppelpunkt:** "**Effizienz:** Prozesse laufen
  schneller." → in Fließtext auflösen oder auf einen normalen Satz kürzen.
- **Emojis:** In Überschriften und vor Bulletpoints raus. Auch das einzelne Emoji am
  Textende hinter dem Aufruf (🚀 💡 ✅ 👇 🔥) ist ein Marker, kein Stilmittel - raus, außer
  die Zielperson benutzt es nachweislich selbst.
- **Anführungszeichen:** Deutsche Texte benutzen „…" oder »…«. Gemischte Zeichensätze im
  selben Text sind ein Marker.
- **Überschriften:** Keine Substantivketten mit Doppelpunkt-Untertitel ("Content-Strategie
  2026: So gelingt der Durchbruch"). Kurze, konkrete Überschriften. Deutsche
  Groß-/Kleinschreibung beachten, kein englisches Title Case.

## 17. Struktur- und Rhythmusmuster

Auch ohne einen einzigen Markerbegriff bleibt ein Text erkennbar, wenn die Form stimmt:

- **Satzlängen-Monotonie:** Fast alle Sätze zwischen 15 und 25 Wörtern. Menschen schwanken
  zwischen 3 und 40.
- **Absatz-Monotonie:** Jeder Absatz drei bis vier Zeilen.
- **Plateau-Tiefe:** Jeder Absatz bleibt auf derselben Abstraktionsebene. Menschen zoomen:
  These, dann ein sehr konkretes Detail, dann wieder raus.
- **Erste-Satz-Echo:** Der erste Satz eines Abschnitts wiederholt die Überschrift.
- **Mini-Fazit pro Abschnitt:** Jeder Abschnitt endet mit einem zusammenfassenden Satz.
- **Vollständigkeitszwang:** Jeder Aspekt bekommt gleich viel Raum, auch der unwichtige.
  Menschen gewichten: Über das interessanteste Drittel schreiben sie die Hälfte des Textes.

## 18. Chatbot-Rückstände

Rückstände aus dem Dialogkontext, die nie im Text stehen dürfen: Gerne! / Selbstverständlich! /
Hier ist Dein Text: / Ich hoffe, das hilft Dir weiter! / Sag Bescheid, wenn ich etwas anpassen
soll. / Als KI-Sprachmodell / Stand meines letzten Trainings / Basierend auf den verfügbaren
Informationen / Hinweis: Die folgenden Angaben sind allgemeiner Natur.

## 19. Anglizismen-Mix

KI streut englische Business-Begriffe ein, die im deutschen Fachkontext unüblich sind:
"Journey", "Insights", "Learnings", "Deep Dive", "Pain Points", "Value Proposition",
"Alignment", "Framework" (wenn "Vorgehen" gemeint ist).

**Regel:** Behalte nur die Begriffe, die die Zielgruppe tatsächlich täglich benutzt. Im
Zweifel deutsches Wort. Ein Handwerksbetrieb hat keine "Customer Journey", sondern Kunden,
die anrufen.

## Schnellprüfung (30 Sekunden)

1. Erster Satz: Weltlage oder Information?
2. Letzter Absatz: Zusammenfassung ohne neuen Inhalt?
3. Wörter aus Abschnitt 3 zählen. Mehr als drei im Text?
4. Aufzählungen zählen. Überwiegend Dreiergruppen?
5. Satzlängen überfliegen: alle etwa gleich lang?
6. Gedankenstriche zählen. Mehr als einer pro Absatz?
7. Steht irgendwo eine konkrete Zahl, ein Name, ein Datum, ein Ort? Wenn nein: Der Text
   sagt nichts.

Punkt 7 ist der wichtigste. Fast alle KI-Texte scheitern an ihm.
